# ספר החיים

מאגר סיפורים אישי וקבוצתי שמצטבר לאורך השנים.

- `index.html` – הגרסה הפעילה (GitHub Pages)
- `versions/` – כל גרסה קודמת נשמרת כאן (v0.1, v0.2...) כדי לאפשר חזרה אחורה
- הנתונים נשמרים בדפדפן (localStorage). גיבוי/שחזור דרך "מרכז שליטה".

## גרסאות
- v0.6 (2.11.2026) – מסכים נקיים: פתיחה בשני צעדים (שם + בחירת מעגלים חופשית, בלי מעגלים קבועים מראש); מסך כתיבה עם העיקר בלבד ו"עוד פרטים" מקופל; פחות טקסטי הסבר; המדריך עבר לכפתור "איך זה עובד"; גדול יותר במחשב; מעגלים ישנים שלא נוצלו נמחקים.
- v0.5 (2.11.2026) – עיצוב "מחברת כרוכה" (כריכת בד, דפי נייר, חוט אדום); מפת קונסטלציה עם חוטים וגשרים בין מעגלים; דף סיפור עם כל הזוויות, תצוגת "זו לצד זו" וסימון מה שרק אחד זכר; "עוד לא סיפרו" עם בקשת זווית; בניית סיפור בחמש שאלות; שדות המשפט/הפרט/השיר/מקום; "הכן לי ניסוח"; מזהים קבועים לאנשים; פתיח אוטומטי לכל פרק. תואם לכל הקישורים והנתונים של v0.4.
- v0.4 (1.11.2026) – סיפורים משותפים: "שתף עם מי שהיה שם" ו"הוסף זווית", אירוע אחד עם כל הזוויות; הזמנת חבורה לפתוח ספרים (קישור start); מדריך שימוש וחזון; בחירת מעגלים/סיפורים לשיתוף כקובץ דיגיטלי או PDF; תזכורת גיבוי; קידום בדף האורח.
- v0.3 (1.11.2026) – הזמנת בן משפחה/חבר לכתוב: קישור בוואטסאפ לדף כתיבה עם הקלדה, הכתבה בקול, הקלטה, הקראה, ביטול וגודל גופן; הזיכרון חוזר בוואטסאפ עם קישור להוספה לספר.
- v0.2 (1.11.2026) – ניהול מעגלים: הוספה, שינוי שם וצבע, מחיקה עם העברת הסיפורים למעגל אחר.
- v0.1 (29.10.2026) – אב-טיפוס ראשון: מפת מעגלים, כתיבה (טקסט/תמונה/הקלטה), ספר בפרקים, מרכז שליטה (בקשות בוואטסאפ, מעקב, הדפסה, גיבוי).
